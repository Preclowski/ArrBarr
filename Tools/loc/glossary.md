# ArrBarr localization glossary

Canonical term per concept. **PL is the reference** (hand-authored). de/es/fr/nl
columns are filled before regenerating those languages (Task 9) and must be used
consistently for every occurrence. Tone: concise, direct, human — see rules below.

## Tone rules (all languages)

- **Buttons / actions:** imperative verb, short. EN "Pause all" → PL "Wstrzymaj wszystko".
- **No filler:** avoid "Proszę…", drawn-out "Aby…" wind-ups, hedging, robotic 1:1 calques.
  Translate intent, not words. ("Aby" is fine mid-sentence where natural, e.g.
  "Użyj 0.0.0.0, aby…" — only avoid it as a stiff opener.)
- **Respect context** (the key's `comment`: button / tooltip / error / label).
- **One term, one translation** — this table governs.
- **Keep product names verbatim:** Sonarr, Radarr, Lidarr, Whisparr, ArrBarr, TMDB, MCP, Quiz.
